# Apps: the how-to steps, and bringing a handoff into a new chat

Read at step 7 of every `handoff`, and before saving when the user names another folder.

## Special places to save

**Another folder.** The user can name another OneDrive or SharePoint folder in plain words ("handoff, and save it in Projects/Budget"): for that command, save there, and say where. A later `pickup` needs that file attached, or the folder named ("pickup budget from Projects/Budget").

**A Cowork project.** Chats in a project share its instructions and context, but a file listed in the project isn't always available to every chat in it. Suggest adding the handoff file to the project's context, and still attach it in the new chat if that chat can't see it.

## How-to steps at the end of a `handoff` reply

People forget how their app starts and finds chats, so after the reply's first lines give these steps, with the real names filled in, in the style just used (after `.push`: `.pull budget`). Give the steps for what comes next: continuing in a new chat, or folding into the master. Microsoft's apps change often: if a step doesn't match what the user sees, say to check Copilot's help.

- **To continue in a new chat:** "Start a new Cowork chat: at copilot.cloud.microsoft or in the Copilot app, choose Cowork next to Chat, or, in a project, start from the project's page. Attach Handoff - budget.md (the attach button's Attach cloud files, or type / and pick the file), then type pickup budget."
- **To fold into the master:** "Open the master chat from My tasks, Search or the recent tasks on the home page. Attach Handoff - budget.md and type fold budget."
- **Renaming chats** (optional): Microsoft doesn't document renaming a Cowork chat. If the app offers it, use the suggested titles; otherwise skip them, since commands find handoffs by file name.
- **Finding old chats:** My tasks (with filters such as Complete and In progress), Search, or the recent tasks on the home page.
- **On a phone:** Cowork runs in the Copilot app on iPhone and Android, but custom skills don't, so type handoff commands on the web or in the Windows or Mac app.
